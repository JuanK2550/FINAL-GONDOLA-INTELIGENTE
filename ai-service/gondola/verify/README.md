# verify/

Verificador de privacidad y de contrato. Revisa los `.jsonl` de salida y falla
si aparece cualquier campo prohibido (edad, genero, rostro, identidad, emocion,
biometria) o si algun evento no valida contra el contrato.

Es nuestra evidencia ante el jurado de que la "privacidad por diseño" no es una
promesa: es un test que se ejecuta.

Vacía en la Fase 1. Se llena en la Fase 4.
